WakeStride Windows·macOS 버전의 업데이트 기록입니다.

⚠ 가안 — 검토 전 초안입니다
v0.2.1 macOS 첫 공개 2026-08-21
  • macOS 지원 추가 — Windows와 같은 v0.2.1로 macOS(Apple Silicon)용 앱을 새로 내려받을 수 있습니다. Cmd 단축키 매핑, macOS 스타일 타이틀바, 기기 간 동기화 시 한글 폴더명 인식 문제를 함께 손봤습니다.
  • 자동 업데이트 기능 추가 — 설정 > 정보에서 새 버전을 확인하고 바로 설치할 수 있는 기능을 Windows에 추가했습니다. 다만 현재 배포 인프라 문제로 일시적으로 비활성화되어 있어, 당분간은 새 버전을 다운로드 페이지에서 다시 받아야 합니다.
  • 위젯이 두 개로 겹쳐 보이던 문제 수정 — 위젯을 켠 채 앱을 닫고 다시 실행하면 위젯이 하나 더 생기던 버그를 고쳤습니다.
  • 매트릭스 화면에 마감 일시 표시 — 할일 항목마다 마감 날짜/시간이 함께 보이고, 기한이 지난 항목은 빨간색으로 표시됩니다.
  • 프로젝트 보드 사용성 개선 — 그룹이 많아 화면을 스크롤해도 월 이동 버튼과 항목 이름이 계속 보이도록 고정했고, 실제 일정이 없는 상위 그룹의 불필요한 이동 화살표를 정리했습니다.
  • 다중 작업공간 사용 시 위젯 동기화 수정 — 작업공간을 전환해도 데스크톱 위젯이 예전 작업공간 데이터를 계속 보여주던 문제를 고쳤습니다.
  • 캘린더 화면 다듬기 — 일정/공휴일 제목의 그림자 효과를 더 은은하게 조정했습니다.
v0.1.0 Windows 첫 공개 2026-08-14
  • 기기 간 데이터 동기화 — 노트 루트로 같은 구글 드라이브 폴더를 여러 기기에서 지정하면, 할 일과 일정이 자동으로 이어집니다. 폴더 색상도 기기와 상관없이 동일하게 보입니다.
  • 첫 실행 화면 추가 — 설치 후 처음 실행하면 언어 선택과 노트 저장 폴더 선택을 바로 안내합니다.
  • 화면별 기능 안내 — 매트릭스·캘린더·노트·대시보드 화면에 처음 들어갈 때 짧은 설명이 한 번 표시됩니다. 설정 > 정보에서 언제든 다시 볼 수 있습니다.
  • 데스크톱 위젯 위치 개선 — 화면 크기와 무관하게 항상 화면 안쪽에 표시되도록 고쳤습니다.
  • 노트 파일·폴더 생성 방식 개선 — 별도 팝업 없이 노트 트리 안에서 바로 이름을 입력해 만들 수 있습니다.
  • 설정 화면 정리 — 언어·글꼴·테마 등 선택 항목을 드롭다운으로 통일하고, 레이아웃을 가지런히 정리했습니다.
  • 단축키 추가 — 3분할·커스텀 레이아웃에서 조합 보기로 전환하는 단축키(Ctrl+5)를 추가했습니다.
  • 설치 프로그램 다국어 지원 — 설치 시 한국어·English·日本語 중에서 언어를 선택할 수 있습니다.
